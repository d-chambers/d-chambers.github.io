Mental Check-In

For personal tracking only. The one-minute reaction task uses 355 ms as a tracking cutoff. Short runs give fewer observations. The symbol task is an SDMT-style adaptation, and practice can improve scores.

For comparisons, use the same task version, device, browser, and input method. This tool has no clinical validation or diagnostic use.

This app is a simple attempt to measure cognitive preparedness in light of changes in diet, sleep, or exercise.

All four activities take about 3 min 30 sec, plus setup and optional practice.

Cognitive clarity

5/10
0 Extremely foggy 5 Functional but sluggish 10 Exceptionally sharp

Visual reaction time 1 min

Tap, click, or press Space as soon as the target appears. Wait for the target between responses.

Symbol matching 90 sec

Use the legend to match each symbol to its digit. Tap a number or use keys 1–9.

Pattern Recall 30 sec

Watch the tiles light up, then tap them in the same order. Finish your last round when time runs out.

Arrow Focus 30 sec

Pick the direction of the middle arrow. The surrounding arrows may point the other way.
